# didi-cards

DIDI Football: картки результатів ставок для Telegram-каналу @didi_football_tips.

Як це працює щоночі:
1. n8n (бот «Football · щоденний огляд 12:00 Київ») після підрахунку ставок о 01:30 Київ кладе заготовку дня в таблицю `didi_card_specs`.
2. Нічне завдання Claude о ~02:05 Київ бере заготовку, запускає `python3 cards.py spec.json` і комітить картинки в `cards/<дата>/` та `cards/latest.json`.
3. n8n-процес «DIDI · картки в канал» о 02:40 Київ читає `cards/latest.json` і публікує картки альбомом у канал.

Ставки на картках умовні (100 €), без справжніх грошей. Картки показують емблеми клубів з API-Sports, якщо заготовка містить `home_logo` та `away_logo`. Емблеми кешуються локально; за відсутності або помилки завантаження залишаються кольорові значки клубів. Флаги турнірів збережено.
Шрифт Inter (SIL Open Font License), див. `fonts/LICENSE-Inter.txt`.

Ординари формуються компактним шаблоном `editorial_cards.render_single`: великі емблеми, назви й рахунок; експреси зберігають багаторядковий вигляд. Помітна нижня плашка уточнює, що ставки умовні.

У `editorial_cards.py` також є окремі шаблони `render_daily(data, path)` та `render_models(data, path)`. Вони не публікуються автоматично: потрібні передані підсумки та період статистики. Порівняння моделей показує кількість прогнозів кожної, щоб не порівнювати відсотки без вибірки.
